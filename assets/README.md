# assets

Optional product pictures for the **Drive info** view. No trademarked artwork is bundled; the app draws a
stylised drive with the vendor's brand colour instead. To show a real photo, drop a PNG here named either

* after the model string as Windows reports it (invalid file-name characters replaced by `_`), e.g. `Samsung SSD 970 EVO 500GB.png`, or
* after the vendor key: `samsung.png`, `crucial.png`, `kingston.png`, `wd.png`, `sandisk.png`, `seagate.png`, `intel.png`,
  `skhynix.png`, `kioxia.png`, `sabrent.png`, `adata.png`, `corsair.png`, `pny.png`, `lexar.png`, `transcend.png`, `team.png`, `sp.png`, `patriot.png`.

Files placed here are copied next to the executable at build time.
